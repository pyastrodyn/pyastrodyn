# Changelog

## 0.0.2

- DOI of the library (all versions) added to the README and the citation file.
- README: where to find the library (GitHub, PyPI, Zenodo), how to cite it, copyright line.
- `.zenodo.json` added, so that Zenodo takes the author with ORCID, the license and the keywords from it.
- No change of the code.

- First version: constellations in Keplerian motion (`walker_delta`,
  `propagate_constellation`, `to_earth_fixed`, `ground_tracks`,
  `elevation_from_station`, `closest_approaches`).
- Basic functions and constants passed through from pyastrodyn-edu 0.0.9
  (Lectures 1 to 5), unchanged.
- Worked example 1: a Galileo-like navigation constellation, as script and notebook.
